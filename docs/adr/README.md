# ADR (Architecture Decision Record)

設計判断の記録を置くフォルダです。「なぜこの設計にしたのか」を短く残し、後から人間も AI も文脈を再構築できるようにします。

AI エージェントとの設計相談は結論がチャットの中に埋もれがちです。結論が出たら ADR として残すことで、次回以降の相談・実装時に AI へ文脈を再説明する手間を減らします。

## いつ書くか

- AI エージェントとの設計相談で結論が出たとき（`/lumino-adr` スキルが作成を支援します）
- 複数の選択肢から迷って 1 つを選んだとき
- 後から「なぜこうなっているのか」と聞かれそうな決定をしたとき

逆に、自明な実装詳細や、すぐに変わりうる暫定対応は書きません。

## 書き方

1. [template.md](template.md) をコピーして `NNNN-<短い英語スラッグ>.md`（NNNN は 4 桁連番）を作成する
2. 1 ページ以内で書く（長い会話の引用はしない。要点のみ）
3. 下の索引に 1 行追加する
